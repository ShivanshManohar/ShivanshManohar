# 🚀 Featured Projects

## 🎫 TicketMindAI — QLoRA Support Ticket Intelligence

End-to-end **LLM fine-tuning and evaluation pipeline** for structured customer-support ticket classification. Fine-tuned a **3.2B-parameter LLM using QLoRA and Unsloth**, training 24.3M parameters (0.75%) on ChatML-formatted support tickets. Built data annotation, dataset preparation, deterministic LLM inference, JSON validation, checkpointing, and benchmark evaluation pipelines.

**Result:** Achieved **100% Category, Subcategory, and Priority accuracy** and **100% exact structured match** on a 540-ticket benchmark.

**Tech:** Python • PyTorch • QLoRA • LoRA • PEFT • Unsloth • Hugging Face Transformers • ChatML • LLM Fine-Tuning • LLM Inference • JSON • Scikit-learn
